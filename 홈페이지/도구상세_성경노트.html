성경노트 : 서피스 펜으로 짓는 성찰과 묵상

종이 위에 만년필로 쓰듯 정결한 디지털 묵상 연구 노트입니다.
서피스 펜의 필압과 햅틱 피드백을 지원하며, 복잡한 기능 대신
성경 본문 주해와 기도문을 한 장의 한지에 온전히 집중하게 돕습니다.

✓ 서피스 펜 햅틱 지원 ✓ 오프라인 단독 구동 ✓ 한지 질감 테마
현재 최신 안정 버전

v0.2.2 (64-bit)

📥 윈도우 설치파일 다운로드

용량: 19.7 MB · 지원 OS: Windows 10/11 x64

성경노트가 제공하는 3가지 사역적 유익

기존 메모장이나 태블릿 앱에서 경험하지 못했던 묵상의 깊이를 드립니다.

✍️

서피스 펜 햅틱 반응

화면에 펜이 닿을 때 실제 종이에 필기하는 듯한 미세 진동 피드백(Haptic)을 지원하여 묵상의 감각을 일깨웁니다.

📖

본문 주해와 기도 분할

좌측에는 성경 본문 구절, 우측에는 나의 묵상과 설교 주해 메모를 동기화하여 한 번에 대조하며 묵상할 수 있습니다.

🔒

완전한 오프라인 보안

서버에 개인 기도문이 전송되지 않으며, 사역자의 컴퓨터 내부 저장소에 안전하고 정결하게 영구 보존됩니다.

🛡️ 윈도우 SmartScreen 보호 알림 안내

개인 오픈소스 소프트웨어 특성상, 초기 설치 시 윈도우 보호 경고가 표시될 수 있습니다. 안전한 프로그램이므로 아래 2단계로 즉시 정상 설치하실 수 있습니다.

STEP 01
파란 팝업창 [추가 정보] 클릭
Windows Defender 알림창에서 문장 아래 링크된 '추가 정보' 글자를 클릭합니다.
STEP 02
[실행] 버튼 누르기
우측 하단에 나타나는 '실행' 버튼을 클릭하시면 안전하게 설치가 완료됩니다.
