## 작업 환경 메모
- 1차 작업은 클라우드 세션(claude.ai/code)에서, 이후 **목사님 PC의 클로드 코드 데스크톱**에서 이어 감.

## ★PC 에서 배포하기 (3단계 — 아직 안 함)
1. 이 브랜치를 받는다: `git fetch origin claude/dazzling-carson-5zss2c` → `git checkout claude/dazzling-carson-5zss2c` (또는 깃허브에서 zip)
2. `홈페이지` 폴더에서 `pip install pillow` → `python _배포만들기.py` → ⚠ 없이 끝나는지 확인
3. `npx wrangler whoami` (풀렸으면 목사님이 `npx wrangler login`)
4. 처음 한 번: `npx wrangler pages project create lowspot --production-branch main`
5. `npx wrangler pages deploy "<저장소>\홈페이지\배포" --project-name lowspot` → 나온 `*.pages.dev` 주소로 확인
   (배포 뒤 `<주소>/robots.txt` 가 `Disallow: /` 인지, 응답 머리에 `X-Robots-Tag: noindex` 가 있는지 확인)
6. 도메인(목사님과 · 대시보드): Workers & Pages → lowspot → Custom domains → `lowspot.net`, `www.lowspot.net`.
   ★**기존 MX 3개·SPF TXT·send.·resend._domainkey·_dmarc·auth.lowspot.net 기록을 건드리지 않는지 화면에서 확인** (인수인계서 3절)
7. 고칠 때마다: 원본 고침 → `python _배포만들기.py` → 5번만 다시

## ★배포 폴더 만드는 법 (고칠 때마다)
- 원본 페이지(`홈페이지/*.html`)를 고친 뒤 `python _배포만들기.py` → `배포/` 가 새로 만들어진다. **`배포/` 안은 직접 고치지 않는다.**
- 필요: `pip install pillow`. 끝에 ⚠ 가 없으면 배포해도 된다(없는 페이지·깨진 링크·noindex 빠짐을 검사함).
- 새 페이지를 만들면 스크립트의 `PAGES` 에, 새 그림 폴더는 `ASSET_DIRS` 에 적는다. 개인 정보 가릴 그림은 `BLUR`.
