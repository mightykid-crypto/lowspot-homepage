- 1차 작업은 클라우드 세션(claude.ai/code)에서, 이후 **목사님 PC의 클로드 코드 데스크톱**에서 이어 감.

## ★배포 폴더 만드는 법 (고칠 때마다)
- 원본 페이지(`홈페이지/*.html`)를 고친 뒤 `python _배포만들기.py` → `배포/` 가 새로 만들어진다. **`배포/` 안은 직접 고치지 않는다.**
- 필요: `pip install pillow`. 끝에 ⚠ 가 없으면 배포해도 된다(없는 페이지·깨진 링크·noindex 빠짐을 검사함).
- 새 페이지를 만들면 스크립트의 `PAGES` 에, 새 그림 폴더는 `ASSET_DIRS` 에 적는다. 개인 정보 가릴 그림은 `BLUR`.
