## 3. 배포 — Cloudflare Pages (무료)
### 이미 된 것(09-30 오레브개발팀)
- Cloudflare 계정: mightykid@gmail.com · 도메인 **lowspot.net 활성**(zone `99958b3a3567e3b719d004d0bdcbbdd3`)
- **이미 쓰는 DNS — 절대 지우거나 바꾸지 말 것**:
  - 루트 **MX 3개(route1/2/3.mx.cloudflare.net) · SPF TXT** — `help@lowspot.net` 메일 받기(Email Routing)
  - `send.lowspot.net`(MX·TXT) · `resend._domainkey` · `_dmarc` — 번호 메일 보내기(Resend)
  - `auth.lowspot.net` — **오레브 인증 서버(Worker orev-auth)** · 홈페이지와 섞지 말 것
- wrangler 로그인은 이 PC 에 되어 있음(`npx wrangler whoami` — 1시간마다 저절로 새로 받음 · 풀리면 목사님이 `npx wrangler login`)

### 할 일
1. **배포 폴더 만들기**: `홈페이지\배포\`(새로) 에 사이트 파일만 복사 — `index.html` · 상세 페이지들 · 새 페이지(오레브·목회시스템·약관·개인정보) · `화면사진\`(쓰는 것만) · 글꼴 · 아이콘. **md·py·시안·리서치·dist·live_chat 은 넣지 않는다.**
2. **검색 차단**(완성 전): `배포\robots.txt` = `User-agent: *` / `Disallow: /` · 각 페이지 `<meta name="robots" content="noindex, nofollow">` · `배포\_headers` 에 `/*` → `X-Robots-Tag: noindex`.
3. **첫 배포**: `npx wrangler pages project create lowspot --production-branch main` (한 번) → `npx wrangler pages deploy "C:\오레브사용자\프로젝트\홈페이지\배포" --project-name lowspot` → 나온 `*.pages.dev` 주소로 확인.
4. **도메인 붙이기**(목사님과 · 대시보드): Workers & Pages → `lowspot` → Custom domains → **`lowspot.net`** 와 **`www.lowspot.net`** 추가. Cloudflare 가 DNS 를 알아서 넣는다 — **기존 MX·TXT·auth 기록을 건드리지 않는지 화면에서 확인.** (www → 루트로 넘기기는 Pages 설정 또는 Redirect Rule)
5. 고칠 때마다 3의 `pages deploy` 만 다시. 잘못되면 대시보드 Deployments 에서 이전 배포로 되돌리기.
6. 비용: Pages 무료(월 500회 배포 · 대역폭 무제한). 도메인 값 외 추가 비용 없음.
