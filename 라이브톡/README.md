# 라이브톡 — 만들기·시험·배포·운영 안내

> 기획: `기획_2026-09-30.md` (★확정 절이 우선) · 쓰는 곳: 한남노회 AI 세미나 2026-11-16(월)~17(화)

## 어떻게 생겼나
| 무엇 | 어디 | 올리는 법 |
|---|---|---|
| 화면(참가자·강사·빔) | `홈페이지/live.html` + `홈페이지/live.js` → 주소 **lowspot.net/live** | 홈페이지와 함께 (`_배포만들기.py` → `pages deploy`) |
| 실시간 서버 | `라이브톡/worker/` (Worker + Durable Object) → **lowspot.net/api/live/*** | 따로 `npx wrangler deploy` (아래) |

- 같은 주소(lowspot.net) 아래 경로만 나눠 쓴다 → **새 하위 주소·DNS 기록이 필요 없다.** 메일(MX·TXT)·`auth.lowspot.net` 은 건드리지 않는다.
- 오레브 인증 서버(orev-auth)와 **다른 Worker** 다(`lowspot-live`). 섞지 않는다.
- 세미나 코드·강사 코드는 **서버 비밀값에만** 있다. 페이지 소스·대화창·문서에 적지 않는다.

## 1. 내 PC 에서 시험하기
```
cd 라이브톡\worker
copy .dev.vars.example .dev.vars        (시험용 코드: 세미나 TEST1116 · 강사 T-MIN-TEST / T-YOON-TEST)
npx wrangler dev --port 8787
```
다른 창에서:
```
cd 홈페이지
python -m http.server 8000
```
브라우저 두 개(또는 창 두 개)로 `http://localhost:8000/live.html?api=http://127.0.0.1:8787` 를 열고,
하나는 강사 코드, 하나는 세미나 코드 + 이름으로 들어가 본다. 빔 화면은 강사 쪽 [🖥 빔 화면].

## 2. 실제 배포 (한 번)
1. 홈페이지가 먼저 lowspot.net 에 붙어 있어야 한다(홈페이지 진행기록의 "PC 에서 배포하기").
2. 비밀값 넣기 — **코드는 새로 정한다**(시험용·옛 시제품 비밀번호 쓰지 않기):
   ```
   cd 라이브톡\worker
   npx wrangler secret put TOKEN_KEY     ← 아무 긴 문자열 (예: 비밀번호 생성기 40자)
   npx wrangler secret put SEMINARS      ← {"세미나코드":{"room":"hannam-2026-11","title":"한남노회 AI 세미나","endsAt":"2026-11-17T18:00:00+09:00"}}
   npx wrangler secret put TEACHERS      ← {"강사코드1":{"name":"민경우","room":"hannam-2026-11"},"강사코드2":{"name":"윤여근","room":"hannam-2026-11"},"강사코드3":{"name":"김민석","room":"hannam-2026-11"}}
   ```
   - 세미나 코드: 참가자가 치기 쉽게 **대문자+숫자 6~8자**(0/O·1/I 헷갈리는 글자 빼기) 예) `HN1116`
   - 강사 코드: 참가자가 짐작 못 하게 **길게**
   - `DEV_CORS` 는 **넣지 않는다**(내 PC 시험용)
3. `npx wrangler deploy` — 끝나면 `https://lowspot.net/api/live/x` 가 `{"error":"없는 주소예요."}` 를 돌려주면 붙은 것.
4. `https://lowspot.net/live` 에서 강사 코드로 들어가 본다.
5. 비용: Workers 무료 플랜 + Durable Object(SQLite) — **배포 직전 무료 한도 다시 확인**. 이 규모(50~100명 × 이틀)는 넉넉한 편.
